# Valleflor - Gestión de mantenimiento (prototipo)

Este prototipo es una página web estática. Para verla tienes dos opciones sencillas:

## 1. Abrir el archivo directamente

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` con tu navegador preferido (doble clic o arrastrándolo al navegador).

## 2. Servirla en `localhost`

Si prefieres usar un servidor local (útil para evitar restricciones de CORS en algunos navegadores), ejecuta en la carpeta del proyecto:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000` en tu navegador. Pulsa `Ctrl+C` en la terminal para detener el servidor.

## Archivos principales
- `index.html`: estructura de la interfaz.
- `styles.css`: estilos y tema oscuro.
- `script.js`: datos de ejemplo y lógica de interacción.

## Nota
El archivo `Mantenimiento` es un marcador temporal sin contenido.
